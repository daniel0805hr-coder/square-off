# Square Off: 말들의 반란

체스 + 전투 2인 도트 게임. 바로 하기: https://daniel0805hr-coder.github.io/square-off/

## 실행
이 폴더에서 아래 명령을 실행한 뒤 브라우저로 http://localhost:8000 접속.

```bash
python3 serve.py
```

## 조작 · 규칙 설정
- **게임패드**: 패드를 꽂고 버튼을 한 번 누르면 인식된다. 패드1 = P1, 패드2 = P2 (연결 순서).
  - 십자키·왼쪽 스틱 = 이동, A = 선택·공격, X = 스킬, B = 취소
  - 턴제: Y = 공격, RB = 방어, LB = 스킬, RT = 집중, LT = 회복
  - PS 패드는 A = ✕, B = ○, X = □, Y = △. 버튼은 **키 설정**에서 바꿀 수 있다 (한 동작에 키 하나 + 패드 버튼 하나)
  - 패드가 연결돼 있으면 화면 도움말이 패드 버튼으로 바뀐다. 온라인 친구도 자기 패드로 조작할 수 있다
- **메뉴 위쪽 세 줄 = 규칙** (왼쪽/오른쪽으로 바꿈, 브라우저에 저장)
  - 맵: 대칭 랜덤 / 고정 맵 3종 (측면 숲 · 중앙 성채 · 모래 평원)
  - 드래프트: 시작 전에 P1부터 번갈아 각자 3칸의 지형을 바꾼다 (킹 시작 칸 제외, 취소 = 그만 바꾸기)
  - 제한시간: 한 수 30초·60초. 시간이 다 되면 컴퓨터가 대신 한 수 둔다 (전투 중에는 멈춤)

## 온라인 (링크 접속)
메뉴의 **온라인 · 인터넷 방** → 화면 아래 링크를 친구에게 보내면, 친구는 링크를 열기만 하면 P2(흑)로 들어온다.

**같은 네트워크(VPN) 방** — 같은 와이파이나 VPN(하마치·라드민·ZeroTier 등)으로 묶인 친구와 할 때. 인터넷 연결 서버를 쓰지 않는다.
1. 호스트 PC에서 `python3 serve.py`로 켜고 http://localhost:8000 접속 (GitHub Pages 주소에서는 안 됨)
2. 메뉴의 **온라인 · 같은 네트워크(VPN) 방** → 화면 아래 주소들 중 친구와 같은 네트워크(VPN) 주소를 친구에게 보낸다 (`http://<IP>:8000/?lan=1`)
3. 친구가 그 주소를 열면 바로 시작. 호스트 PC 방화벽이 8000번 포트를 막으면 열어 줘야 한다
- 호스트가 게임 전체를 돌리고 화면을 영상으로 보낸다. 친구는 영상을 보며 자기 키보드·마우스 입력만 보낸다 (`src/net/online.js`).
- 친구는 화면 오른쪽 아래 **[키 설정]**에서 자기 키를 바꿀 수 있다 (친구 브라우저에 저장).
- 호스트는 게임 탭을 화면에 띄워 둬야 한다 (탭을 내리면 브라우저가 게임을 멈춰 친구 화면도 멈춤).
- `localhost` 링크는 같은 컴퓨터에서만 열린다. 멀리 있는 친구와 하려면 이 폴더를 인터넷에 올려야 한다 (GitHub Pages·itch.io 등).
- 연결 주선은 PeerJS 공개 서버를 쓴다. 일부 회사·학교 네트워크에서는 P2P 연결이 막힐 수 있다.
  - 방 만들기가 10초 안에 안 되면 호스트 화면에, 친구가 15초 안에 화면을 못 받으면 친구 화면에 안내가 뜬다 (다른 네트워크·핫스팟으로 다시 시도).
  - 그래도 안 되면: 호스트가 2인 대전을 켜고 Parsec이나 디스코드 화면 공유로 보여 준다.

## 구조
| 파일 | 역할 |
|---|---|
| `src/logic/chess.js` | 체스 룰 (화면·입력과 분리된 순수 로직) |
| `src/logic/battle.js` | 탑다운 전투 룰 (순수 로직) |
| `src/logic/turnBattle.js` | 턴제 전투 룰 (순수 로직) |
| `src/logic/terrain.js` | 칸 지형(투기장·성채·숲), 대칭 랜덤 맵 생성, 고정 맵 |
| `src/logic/chase.js` | 추격전 룰·숲 미로 (순수 로직) |
| `src/logic/balance.js` | **밸런스 수치** — 스탯·기물별 기술·보상·회복량 등 조정은 여기서 |
| `src/logic/units.js` | 판 위 기물의 HP·공격력 (베테랑 포함) |
| `src/logic/ai.js` | 테스트용 컴퓨터 상대 (체스 수 + 전투 봇) |
| `src/input/controls.js` | 키 → `{ player, action }` 명령 변환, 키 배치, 온라인 친구 입력 전달 |
| `src/input/gamepad.js` | 게임패드 버튼 → 키 입력 (`Pad1:B0` 같은 코드) |
| `src/net/online.js` | 링크 접속 온라인 (인터넷 방·같은 네트워크 방, 친구 화면) |
| `src/net/guestKeys.js` | 친구 화면의 키 설정 창 |
| `src/scenes/BoardScene.js` | 체스판 화면 |
| `src/scenes/BattleScene.js` | 탑다운 전투 화면 (투기장) |
| `src/scenes/TurnBattleScene.js` | 턴제 전투 화면 (성채) |
| `src/scenes/ChaseScene.js` | 추격전 화면 (숲) |
| `src/scenes/KeyConfigScene.js` | 키 설정 화면 |
| `src/ui/style.js` | 공통 글꼴·색·판 위 말 |
| `src/ui/pieceArt.js` | 체스말 도트 그림 6종 (32×32). 백 = 상아+금+사파이어, 흑 = 흑단+은+루비, 베테랑·맞은 순간 변형 |
| `src/ui/frame.js` | 화면 공통 틀: 패널·창·판 테두리·돌벽·전투 정보 판 (흑단 + 금 장식) |
| `src/ui/fighter.js` | 전투 화면의 말 (발밑 팀 색 링, 방향, 걸음, 맞음, 쓰러짐) |
| `src/ui/pixelfx.js` | 도트 이펙트(타격 불꽃·연기·헤일로·결전 유리 깨짐 등)를 화면에 그리는 연결 |
| `tests/` | 룰·전투 테스트 |

## 사용한 외부 리소스
`lib/` 폴더에 넣어 두어 인터넷 없이도 게임이 열린다 (온라인 대전만 인터넷 필요). 각 라이선스 파일도 함께 있다.
- Phaser 3.90.0 (MIT) — `lib/phaser-3.90.0.min.js`
- Galmuri 폰트 2.40.3 (SIL OFL 1.1) — `lib/galmuri/` (게임에서 쓰는 Galmuri11·9·14만)
- PeerJS 1.5.4 (MIT) — `lib/peerjs-1.5.4.min.js`, 온라인 연결
- pixelfx 0.3.1 (MIT, https://github.com/patch-gg/pixelfx) — `lib/pixelfx/`, 도트 이펙트. 일부 이펙트는 Hugo Duprez의 MIT 코드를 바탕으로 함 (`lib/pixelfx/NOTICE.md`)
